# Real Life Notes — 用户手册

> 面向访客与管理员的使用说明。技术实现细节见《技术手册（docs/tech-manual.md）》。

---

## 1. 这是什么

一个把 GitHub 仓库当作后端的个人博客/笔记站：
- **访客**无需任何账号即可浏览、搜索、阅读、评论。
- **管理员**在浏览器里用 GitHub 个人访问令牌（PAT）直接发布内容，一次保存 = 一次 Git 提交，历史可追溯、可回滚。
- 完全静态托管（GitHub Pages 等），无服务器、无数据库、无第三方广告。

## 2. 快速开始（站长）

### 2.1 部署站点
1. 把本项目推送到自己的 GitHub 仓库。
2. 仓库 **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / root** → Save。
3. 站点地址：`https://<你的用户名>.github.io/<仓库名>/`。若要绑自定义域名，在 Pages 设置里配置。

### 2.2 创建访问令牌（fine-grained PAT）
1. GitHub → 右上角头像 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**。
2. **Repository access**：Only select repositories → 选本项目仓库。
3. **Repository permissions** → 勾选 **Contents: Read and write**（Metadata: Read 会自动附带）。
4. 生成并复制 token（形如 `github_pat_…`；**只显示一次**，记得保存到密码管理器）。
5. 建议开启分支保护：Settings → Branches → Add rule（要求 PR），防止误删。

### 2.3 连接管理后台
1. 打开站点 → 页脚「**管理**」进入 `/admin/`。
2. 在「目标仓库」粘贴仓库地址（浏览器地址栏 URL / HTTPS / SSH / 裸 `owner/repo` 均可，实时识别提示）。
3. 粘贴 token。浏览器会提示**保存到密码管理器**，下次自动填充。
4. 连接成功即进入文章列表。
   - 若是**全新空仓库**，会自动跳转「设置 → 初始化仓库」，点「初始化」一次性写入站点代码文件，之后按提示开启 Pages。

## 3. 访客指南

### 3.1 浏览文章
- **首页**：最新文章卡片（含分类、日期、摘要、标签、阅读时长、置顶标记），底部翻页。
- **分类**：顶部导航（笔记/生活/工作…）点击即跳转对应分类列表；「全部」回到所有文章。
- **归档**：页脚「归档」→ 按月分组的全部文章；分类列表页还有「该分类归档」入口。
- **标签**：页脚「标签」→ 标签云（显示每个标签的文章数）；点击标签查看该标签全部文章；文章卡片上的标签也可直接点。

### 3.2 搜索
- 列表页顶部搜索框输入关键词，点「**搜索**」或回车提交。
- 匹配范围：标题、摘要、标签、分类名、正文。
- 结果页显示「搜索「关键词」· N 篇」，命中的标题有高亮；点「清除 ✕」回到全部。
- 小技巧：`/` 键（列表页）可直接聚焦搜索框。

### 3.3 阅读文章
- 点击卡片进入详情页；地址形如 `post.html?p=content/notes/xxx.md`，可直接分享该链接。
- 详情页能力：
  - **目录**：正文顶部 TOC，点标题跳转，滚动时当前章节高亮。
  - **字号**：正文右上「Aa」按钮，点击弹出滑动条调节阅读字号，左端「↺」恢复默认。
  - **阅读进度**：页面顶部细进度条。
  - **代码块**：行号 + 右上角「复制」按钮；支持高亮与 LaTeX 公式。
  - **图片**：点击可放大（灯箱），Esc 或点外部关闭。
  - **导航**：底部上一篇/下一篇（同分类）、相关文章（同标签）。
  - **快捷键**：`←` 上一篇、`→` 下一篇（在输入框里时不会误触发）。
- **深色模式**：右上角 🌗 切换（亮 / 暗 / 跟随系统）。

### 3.4 评论
- 站点开通评论时，文章底部有评论区：
  - 有评论：直接展示；点「在 GitHub 参与评论」到 GitHub 回复。
  - 无评论：点「写第一条评论」→ 用你的 GitHub 账号登录后发表（会自动带好文章标题和标签）。
- 评论内容支持 Markdown 与 @提及。

### 3.5 订阅
- 页脚「订阅 RSS」：RSS 阅读器可订阅全站更新（全文输出）。

### 3.6 分享
- 详情页「复制链接」一键复制当前文章地址分享。

## 4. 管理员指南

### 4.1 界面总览
连接后左侧导航：**文章 / 分类 / 设置**。

### 4.2 写文章
1. 「文章」列表 → 「**新建文章**」。
2. 填写：
   - **标题**（必填）
   - **分类**（下拉；可在「分类」页先建好）
   - **标签**（逗号分隔，可多个）
   - **日期**（默认当前时间）
   - **置顶**：勾选后列表优先展示
   - **草稿**：勾选=存草稿（访客看不到，只有你能在后台看到）
   - **正文**：Markdown 语法（支持标题、列表、表格、代码块、LaTeX 公式 `$...$`/`$$...$$`、图片）
3. 右侧**实时预览**；工具栏可插入常用格式，支持快捷键。
4. 插入图片：把图片**粘贴**进正文，或拖拽/选择文件上传，会作为图片文件写入仓库。
5. 点「**保存草稿**」或「**发布**」。

> 发布 = 一次 Git 提交（文章 + 索引 + RSS 原子更新）。发布后 raw 内容立即生效，GitHub Pages 构建完成后全站可见（通常几十秒）。

### 4.3 编辑 / 删除 / 批量操作
- **编辑**：列表行「编辑」，改完保存。
- **删除**：行「删除」或勾选后批量删除（一次提交）。
- **批量**：勾选多篇 → 顶部操作条「批量发布 / 批量存草稿 / 批量删除」；「批量移动分类」可把多篇挪到别的分类。
- 列表有筛选框（按标题/内容过滤）与「查看」按钮（跳前台预览）。

### 4.4 管理分类
- 「分类」页：新增（填 id + 名称 + 图标 + 描述）、改名、删除（删除前提示会影响该分类下的文章）。
- 分类 id 用于目录名（小写字母/数字/`-`/`_`），会显示在顶部导航。

### 4.5 站点设置
- 「设置」页可配置：
  - 站点标题 / 副标题 / 作者 / 站点地址（留空则用相对路径）
  - **评论**开关与评论标签
  - 「**重新生成 RSS / 站点地图 / robots**」按钮（内容有变时会自动重建，手动重建用于兜底）
  - **初始化仓库**（空仓库时）
- 保存设置 = 一次提交。

### 4.6 数据与安全
- 所有内容变更都在 GitHub 仓库留有 Git 历史，可在 GitHub 上查看/回滚。
- token 仅保存在浏览器内存与你的密码管理器，**本站不存储**；泄露时到 GitHub 撤销并重建。
- 建议定期把仓库 clone 一份做异地备份（Git 本身就是备份）。

## 5. 常见问题（FAQ）

| 问题 | 说明 |
| --- | --- |
| 发布了但前台没变化？ | 等 GitHub Pages 构建完成（几十秒到一两分钟）；刷新页面；若一直不变可能是 CDN 缓存，等缓存过期或强制刷新（Ctrl/Cmd+Shift+R）。 |
| 编辑内容提示「未保存的修改」？ | 离开前忘记保存，确认后离开会丢失；先保存再切换。 |
| 上传图片太大？ | 当前未自动压缩，建议控制图片体积（长边 ≤ 2000px、体积 < 1MB）以保持仓库轻量。 |
| 草稿为什么别人能看到直链？ | 不会。草稿不进公开列表，直链也不渲染（返回 404 提示）。 |
| 评论需要登录吗？ | 评论用 GitHub 账号（点链接跳到 GitHub 登录后发表）。 |
| 站点如何更新版本？ | 直接拉取本项目最新代码合并/覆盖非内容文件即可；内容（content/、assets/images/）不要动。 |
| 换了电脑 token 还要重新输入？ | 是的，token 存本地密码管理器，每台设备/浏览器各自保存。 |
